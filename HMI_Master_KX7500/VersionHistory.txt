Version			: V1.4.0.0
Date Updated	: 14/10/2026
Updated By		: CK
Changes			:
1. Add OfflineMode in MachineConfig.xml to run the HMI without PLC, COM port and TCP server (simulated PLC memory).
2. PLC IP address and port read from MachineConfig.xml (PLCIPAddress, PLCPort) instead of hard-coded.
3. Add UseKVStudioSimulator in MachineConfig.xml (value for KV DataBuilder KVSimulator, default true as before).
4. FOUP CSV folder configurable (FoupCsvFolder). Falls back to <HMI folder>\FOUP CSV\ when D: drive does not exist.
5. Fix Alarm.mdb path: now read from MachineSettings\Alarm.mdb of the running build (Debug read the Release folder before).
6. Add Robot page (Technician/Pentamaster): robot status and position, power on/run/pause/stop/reset, speed,
   teach mode, jog (Base/Tool, 0.01-10.00 mm/deg), hold-to-move, teach point, load/save robot recipe points.
7. Add Recipe page (create copy, rename, delete, view robot points). Lot Entry: recipe drop-down; New Lot loads
   the recipe's robot points to the robot before the lot is created.
8. Chinese menu names corrected (Recipe, Robot).
